# Contributing

Thanks for helping improve the RevoGrid feature examples.

1. Configure trial or licensed package access without committing credentials.
2. Install with `pnpm install --frozen-lockfile`.
3. Keep Vanilla TypeScript, React, Vue, and Angular behavior aligned.
4. Run `pnpm test`, `pnpm build:frameworks`, and `pnpm test:e2e`.
5. Regenerate media only for intentional visual changes and include the review contact sheet in the pull request.

Changes to the commercial RevoGrid implementation belong in the private Pro or
Enterprise source repository. This repository owns examples, recipes, tests,
documentation, and media only.
