# Basic scheduler

A resource timeline with eight team members and three starting events. Drag an empty time range to open the event editor; existing events can also be edited, moved, resized, or deleted. Hover an event to see its dates and assigned people. Changes are kept in memory.

Use `SchedulerBasic.ts`, `SchedulerBasic.tsx`, `SchedulerBasic.vue`, or `SchedulerBasicAngular.ts` for your framework. The shared `data.ts` contains the resources, events, and scheduler configuration.
