# Basic scheduler

A resource timeline with eight team members and three starting events. Drag an empty time range to create an event; existing events can also be edited, moved, resized, or deleted. The included trial version creates events directly; changes are kept in memory.

Use `SchedulerBasic.ts`, `SchedulerBasic.tsx`, `SchedulerBasic.vue`, or `SchedulerBasicAngular.ts` for your framework. The shared `data.ts` contains the resources, events, and scheduler configuration.
