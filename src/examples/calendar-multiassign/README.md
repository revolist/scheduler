# Multiassignment calendar

A team calendar with Day, Week, Month, Year and Schedule views, shared event editing, resource filters and multiple assignees.

Use `CalendarMultiAssign.vue`, `CalendarMultiAssign.ts`, `CalendarMultiAssign.tsx` or `CalendarMultiAssignAngular.ts` for your framework. `demo.ts` owns the shared state and controls; `data.ts` owns the sample events and resources. Portraits are bundled under `assets/`.
